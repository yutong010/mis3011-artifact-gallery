# MIS3011 — Student Artifact Gallery, Fall 2026

https://yutong010.github.io/mis3011-artifact-gallery/

A public index of artifacts built by students in this course. Every entry
links to something you can open.

## Adding an artifact

Edit `data/artifacts.js` — nothing else, and never `index.html`. The template,
the field list, and the rules that matter (consent, privacy, the `one_liner`
cap) are in the comment at the top of that file.

## Layout

`index.html`, `assets/site.css` and `assets/render.js` are byte-identical to
the [IBA6316 · MDS5370 gallery](https://github.com/yutong010/iba6316-mds5370-artifact-gallery).
Only `data/` differs. To start a gallery for another course: copy the repo,
rewrite `data/config.js`, empty `data/artifacts.js`.
